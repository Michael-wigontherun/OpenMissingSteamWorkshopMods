# OpenMissingSteamWorkshopMods
Made for Stellaris but it can be adapted to whatever

Will generate a text file based on a Stellaris Playlist json of whatever mods you are missing.

## Requirements
.Net 9 Runtime or newer

## Paramaters
This Consol Application requires atleast two paramater to run.
param 1 : stellaris playlist json path
Example : \"C:\\Users\\[user]\\Desktop\\Everything_but_a_salad.json\"
Console.WriteLine();
param 2 : stellaris workshop mods folder path
Example : \"H:\\SteamLibrary\\steamapps\\workshop\\content\\281990\"
Console.WriteLine();
param 3 : Output folder for the report.
If none will write to the same folder as this program.

## Build Requirements
- Visual Studio
- .net9 run time
